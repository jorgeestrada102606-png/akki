# 🌸 AkkiNovia — Love, Chunibyo & Other Delusions

Plataforma web personalizada para disfrutar de la colección completa de *Chuunibyou demo Koi ga Shitai!*.

🔗 **Sitio Web en Vivo**: [https://jorgeestrada102606-png.github.io/akki/](https://jorgeestrada102606-png.github.io/akki/)

---

## ✨ Características

- 🎬 **Temporada 1 completa**: 12 episodios listos para reproducir con Google Drive Embed.
- ⚙️ **Panel de configuración**: Posibilidad de ingresar IDs de Google Drive para la Temporada 2 y la Película directamente en la web.
- 🌸 **Efectos interactivos**: Lluvia de flores de cerezo y diseño temático anime moderno y responsivo.
- 💾 **Persistencia local**: Guarda los episodios configurados en el navegador.
